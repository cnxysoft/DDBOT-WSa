# 模板文件写入与热更新验收

日期：2026-11-18。PR #52 修复 QQ 状态路径后，新 CI 暴露的独立问题。

## 失败与原因

[PR CI 44146449432](https://github.com/cnxysoft/DDBOT-WSa/actions/runs/44146449432) 的 `TestTemplateRuntimeEnableDisableAndInvalidRetains` 失败，同提交推送 CI 的测试通过。新增 QQ 回归通过。

模板监听原先收到每个文件事件就立即重建。原地编辑先截断、再写正文，监听可能读到空文件；空内容合法，导致只包含默认模板的候选替换运行中的自定义模板。最终无效正文虽然被拒绝，保留的已是错误的中间版本。这是产品时序缺陷，不能通过延长测试等待或直接重跑 CI 解决。

## 修复与验证

自定义模板监听合并 100ms 连续事件后再构建；构建期间若收到新模板事件，丢弃候选并重新等待。原有语法校验与 activeLoader 身份保护保留，关闭后停止计时器并排空监听。原回归不再固定等待 50ms，而是等待监听实际记录无效模板错误后验证旧代仍在运行。

独立代理 `independent_completion_audit` 编写 `lsp/template/loader_write_acceptance_test.go`：

- 真实文件先 `O_TRUNC`，保留 30ms 空窗，再写无效正文。旧实现可复现丢失自定义模板；修复后等待实际错误处理，旧内容仍可执行。
- 有效原地编辑、临时文件原子替换可以继续应用。
- 待处理事件在禁用或关闭后不能重新发布，关闭返回时旧监听已排空。
- 合法稳定空文件、删除和重建继续支持，内嵌默认模板保留。

主代理根模块全量 `CGO_ENABLED=0 go test ./... -timeout 120s` 通过；模板相关竞态检查通过。独立模板包全量竞态检查及三组真实监听场景重复 10 轮竞态检查均通过，`git diff --check` 通过。竞态检查对既有 gls 依赖使用 `-gcflags=github.com/modern-go/gls=-d=checkptr=0`，保持竞态检测开启。独立结论允许提交、推送，不合并。

## 边界

事件合并针对普通短截断/写入过程，不提供文件写入锁或原子比较替换。外部编辑器若分段写入并暂停超过合并窗口，合法的中间内容仍可能被视作一次完成编辑；需要避免此类中间版本时，应写入临时文件后原子替换。此轮不涉及真实平台账号或浏览器验收，PR 用户测试清单仍待完成。
