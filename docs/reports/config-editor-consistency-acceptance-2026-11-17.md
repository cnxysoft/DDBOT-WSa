# 配置编辑体验与并发保存验收报告

日期：2026-11-17。分支：`codex/config-hot-reload`。基于已验收提交 `bab6cf6` 继续完善。

## 问题与改动

上一轮报告列出了三项缺口：保存或扫码成功后重新读取配置会丢失其他草稿；变更 WebUI 监听地址或关闭服务后页面缺乏引导；外部编辑与慢资源准备并行时，外部文件可能被在途保存覆盖。本轮围绕这三项完善。

### 草稿与版本基线

配置表单记录字段原文、复选状态、凭据清除动作及编辑基线，重新渲染时只更新未编辑字段，重放其他草稿。高级 JSON 保留原文和原始比较基线，即使 JSON 尚未写完也不因其他保存或扫码完成而丢失。平台配置弹层关闭后仍保留草稿，重新打开恢复。

保存捕获此次提交快照，成功时仅清理已提交且没有继续编辑的字段；请求在途期间的后续输入、其他表单和高级 JSON 草稿继续保留。外部更新触及草稿基线时提示核对。草稿保存在页面内存，退出或重新登录时清空，不把凭据草稿写入浏览器存储；不承诺关闭页面、硬刷新或新地址页面之间迁移草稿。

`GET /api/v1/config` 的强 ETag 是原文件字节的 SHA256，成功保存返回新 ETag，响应体保持既有格式。WebUI 提交可选 If-Match，旧版本或弱版本条件返回 HTTP 409；无条件头的旧客户端仍兼容。条件匹配支持强标签列表及存在性通配符，显式空条件拒绝。格式或注释变动同样改变文件身份，不用运行版本代替原文件版本。

同页保存队列只沿本页成功提交的 ETag 链推进；迟到 GET 不得回退版本。409 保留草稿、读取最新基线并提示人工核对，不自动重发旧 patch。刷新接受新的源版本时废弃旧保存链，并拒绝尚未发出的旧基线操作；即使用户恢复了字节完全相同的旧备份，新手动保存仍可使用恢复后的版本，旧排队操作不会趁机重发。

### 外部文件改动保护

WebUI 配置保存、初始化向导和公开凭据回写 API 共用 `ConfigFileVersion`，同时捕获源字节和文件存在性。候选资源准备完成后，在暂存及每次 rename 前重新检查；原文不匹配、文件被删除，或原本缺失的文件被创建时，拒绝覆盖、中止候选资源并保留外部文件。冲突错误不包含文件路径或凭据，配置 API/向导返回 HTTP 409。

使用同目录唯一临时文件并同步写入，再原子替换；失败清理临时文件。WebUI/向导首次以排他创建方式保留原文 `.bak`，已有备份一律保留，不在每次保存时覆盖。备份失败会拒绝本次保存；仅尝试清理身份仍对应自己创建的未完成备份，不引入对硬链接文件系统能力的依赖。

该机制检测慢准备期间的外部修改，不构成操作系统级的原子比较替换。不共用写锁的编辑器在最后一次检查与 rename 之间仍有微小竞争窗口；需要完全互斥时应避免同时写入。

### 管理服务访问引导

成功保存实际变更 `admin.addr` 或关闭监听时，响应增加 `navigation`。启用状态带提交后的实际监听地址，`:0` 使用系统分配端口；关闭状态只返回 `enabled:false`。无关保存、地址未变或候选监听失败不会误报迁移。

WebUI 展示持续的全局引导，停止旧地址上的周期请求、SSE 重连和扫码轮询；新链接由严格的 host/port 格式构造，通配地址替换为当前页面主机名，无 token/query，不自动跨源登录或跳转。HTTPS、反向代理和子路径访问明确提示检查公开地址及代理目标。关闭服务时提示通过配置文件热更新重新启用。

此引导针对当前页面发起并成功完成的保存。通过外部编辑器迁移地址后，需自行访问新地址。草稿仍留在旧页面，打开新地址不会自动转移草稿。

## 实现与独立验收

主代理实现导航元数据与真实 HTTP 回归、集成读审及报告；`shared_resource_reload` 实现版本检查、ETag、备份及三个保存入口；`platform_live_login` 实现草稿、队列版本和页面引导。`independent_completion_audit` 仅审查和编写独立验收测试，不修改产品实现。

最初真实外部修改探针在修复前复现了 HTTP 200 覆盖文件和凭据假成功；修复后转绿。导航测试最初启动了与测试无关的全局推送收集器，后台数据库回填与后续测试重置全局数据库产生竞态；测试改为真实路由和监听器的最小 Server，保留保存及迁移链，避免泄漏无关后台任务。

前端独立验收发现并闭环两处并发边界：监听迁移后迟到的登录成功响应会清空保留草稿；恢复旧备份导致源 ETag 回到旧值时，旧成功保存映射会污染新基线，既可能让新保存持续冲突，也可能使旧排队 patch 再次匹配源文件。对应永久回归要求迁移废弃登录响应、接受新源版本时废弃旧保存链，并验证恢复备份后可重新手动保存。
